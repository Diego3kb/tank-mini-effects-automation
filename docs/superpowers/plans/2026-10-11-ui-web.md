# UI Web Tank Mini — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** UI web local (Flask + vanilla JS) para visualizar/editar bancos `.atkm`, importar/exportar com o pedal e gerenciar a biblioteca CAB/AMP.

**Architecture:** Um app Flask (`tools/ui.py`) serve uma única página e uma API JSON. Leitura offline importa `atkm.load`/`preset_config.show` direto; escrita e device vão por subprocess (`sys.executable tools/...`), reaproveitando a CLI já testada. Edição gera plano JSON com `expected_sha256` (REGRAS #4) e chama `preset_config.py apply`.

**Tech Stack:** Python 3.14, Flask >=3.0 (nova dependência), HTML/CSS/JS vanilla sem CDN, pytest.

**Spec:** Conversa desta sessão (grilling, rodadas 1–2) + `docs/GUIA-COMPLETO.md`, `docs/REGRAS.md`, `docs/AUTOMACAO.md`, `docs/MAPA.md`, `docs/EFEITOS-FABRICA.md`.

## Global Constraints

- Offline total: sem CDN, sem fontes externas, sem chamadas de rede além de `127.0.0.1:8517`.
- Zero dependência nova além de `flask` em `requirements.txt`.
- Toda escrita de banco passa por `preset_config.py apply` (subprocess) — nunca reescrever a lógica de edição.
- Todo plano JSON gravado em `plans/plano-<timestamp>.json` com `expected_sha256`.
- Banco editado gravado como arquivo NOVO: `<pasta-do-original>/<stem>-edit-<HHMMSS>.atkm`.
- Device: só por subprocess de `tools/m_efcs_automation.py`; UI nunca importa pywinauto.
- `save-cab`/`save-amp` exigem campo `confirm: true` no request (confirmação dupla na UI antes).
- Porta fixa 8517; navegador abre automaticamente.
- Subprocess sempre com `sys.executable` e `cwd=PROJECT` (raiz do projeto).

## Review Focus

1. **Pedal desconectado** → botão device mostra o stderr do subprocess e a UI continua de pé. Teste no Task 4 (subprocess simulado com exit 1).
2. **Arquivo não-ATKM em /api/bundle** → HTTP 400 com mensagem de `load()`, nunca 500. Teste no Task 2.
3. **Hash mudou entre abrir e salvar** → `apply` recusa; UI exibe o erro e sugere recarregar. Teste no Task 3.
4. **Destino já existente** → `apply` recusa; nome de saída com sufixo de timestamp evita colisão. Teste no Task 3.
5. **save-cab/save-amp sem confirmação ou item inválido** → 400 sem `confirm: true`; item fora da lista vira stderr exibido. Teste no Task 5.

# tests/test_ui_edit.py
import sys, json, hashlib
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "tools"))
sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "tests"))
from ui import app
from atkm import TRAILER

def client():
    app.config["TESTING"] = True
    return app.test_client()

def test_edit_cria_plano_e_banco(tmp_path):
    from conftest import make_bundle
    bundle = tmp_path / "b.atkm"; sha = make_bundle(bundle)
    plans_dir = tmp_path / "plans"; plans_dir.mkdir()
    app.config["PLANS_DIR"] = plans_dir
    r = client().post("/api/edit", json={
        "path": str(bundle),
        "edits": {"1A": {"amp.gain": 80, "reverb.enabled": 0}}})
    assert r.status_code == 200, r.get_json()
    out = Path(r.get_json()["output"])
    assert out.exists() and out.read_bytes().endswith(TRAILER)
    plano = json.loads(Path(r.get_json()["plan"]).read_text(encoding="utf-8"))
    assert plano["expected_sha256"] == sha
    assert plano["edits"] == {"1A": {"amp.gain": 80, "reverb.enabled": 0}}
    assert Path(r.get_json()["plan"]).parent == plans_dir

def test_edit_arquivo_ausente(tmp_path):
    app.config["PLANS_DIR"] = tmp_path / "plans"; app.config["PLANS_DIR"].mkdir()
    r = client().post("/api/edit", json={"path": str(tmp_path / "naoexiste.atkm"), "edits": {"1A": {"amp.gain": 10}}})
    assert r.status_code == 400
    assert list((tmp_path / "plans").iterdir()) == []  # nenhum plano gravado

def test_edit_apply_falha(tmp_path, monkeypatch):
    import ui
    from conftest import make_bundle
    bundle = tmp_path / "b.atkm"; make_bundle(bundle)
    app.config["PLANS_DIR"] = tmp_path / "plans"; app.config["PLANS_DIR"].mkdir()
    monkeypatch.setattr(ui, "run_tool", lambda args: __import__("subprocess").CompletedProcess(args, 1, stdout="", stderr="hash original diferente ou ausente"))
    r = client().post("/api/edit", json={"path": str(bundle), "edits": {"1A": {"amp.gain": 10}}})
    assert r.status_code == 400 and "hash original diferente" in r.get_json()["error"]
